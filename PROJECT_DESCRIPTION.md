# Buy Verse - E-Commerce Application

## Overview
Buy Verse is a comprehensive e-commerce mobile application built with Flutter for seamless buying and selling experiences. The platform serves both Admin/Business Owners and Customers with bilingual support (Arabic/English) and real-time order management.

## Key Features
- **User Authentication**: Secure login, registration, and OTP verification
- **Product Management**: Add, edit, delete products with image uploads
- **Category System**: Organize products into different categories
- **Shopping Cart**: Add products, manage quantities, and track totals
- **Order Management**: Track order status and manage orders
- **Inventory Tracking**: Monitor stock levels and availability
- **Payment Processing**: Multiple payment methods including cash on delivery
- **Real-time Notifications**: Live order status updates and alerts
- **Bilingual Support**: Full Arabic and English language support
- **Profile Management**: Manage personal and business information

## Technology Stack
- **Framework**: Flutter (Cross-platform mobile development)
- **State Management**: BLoC (Business Logic Component)
- **Networking**: Dio for HTTP requests
- **Local Storage**: SharedPreferences and Hive
- **Notifications**: Firebase Cloud Messaging (FCM)
- **Localization**: Flutter localization for multi-language support
- **Image Handling**: Cached network images
- **API Integration**: RESTful API with token authentication
